# Sons — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dix moments de l'app sonnent, dans trois palettes comparables sur l'appareil, avec un réglage « Sons » ; une seule palette est livrée.

**Architecture:** `AudioService` devient un service par moment (`SoundCue`) : un `SoundPlayer` préchargé par moment pour la palette active, injectable (fausse en test), persistance du réglage et de la palette, règle « un son par geste » sur une microtâche. Les points d'appel lisent le service via provider (`context.read<AudioService?>()` dans les widgets, injection dans les providers). Les fichiers wav sont produits par un script Python commité, depuis Mixkit, Kenney et une synthèse numpy.

**Tech Stack:** Flutter 3.47 / Dart ^3.11, provider, audioplayers 6.8.1 (déjà dans le pubspec), shared_preferences ; Python 3 + numpy + ffmpeg pour l'import.

**Spec:** `docs/superpowers/specs/2026-10-23-sounds-design.md`

## Global Constraints

- Aucune dépendance nouvelle. Tout en `flutter_app/`.
- Fichiers : wav PCM 16 bits mono 44,1 kHz ; pas de silence de tête > 5 ms ; crête −3 dBFS (`press` : −10 dBFS) ; ≤ 400 ms sauf `trackerOpen`, `trackerClose`, `trackerCreate` ≤ 700 ms ; < 100 Ko chacun.
- Un dossier par palette, `assets/sounds/<palette>/<moment>.wav`, chaque dossier listé dans `pubspec.yaml` ; l'entrée `assets/sounds/` et les deux mp3 disparaissent.
- Clés de préférences : `sounds_enabled` (défaut `true`), `sounds_palette` (défaut `paper`).
- Traductions dans les quatre locales de `LanguageProvider` (fr, en, zh, zh-Hant).
- `play` ne lève jamais, n'attend jamais ; un son avant la fin du chargement est perdu, pas mis en file.
- Ton : léger, jamais un spectacle ; `press` plus discret que tout.
- Pas de son : suppression d'un tracker, légende prise comme pinceau. Pas de volume, pas de vibration.

## Review Focus

1. Un `play` pendant le démarrage à froid (préférences pas encore lues, lecteurs pas chargés) : silence, jamais une exception.
2. Deux points posés à 50 ms d'écart : deux sons, le second repart du début, aucune erreur de lecteur occupé.
3. `setPalette` pendant qu'un son joue ou qu'un chargement est en cours : l'ancienne génération est jetée, aucune fuite, aucun crash.
4. Un `AudioPlayer` qui ne peut pas être construit (plugin absent, test sans binding) : le service se construit quand même et reste muet.
5. Un pop-up fermé par le retour système ou par la barrière sonne `dialogClose` une seule fois ; `press` puis `dialogOpen` dans le même tour ne fait qu'un son.

/// A [SoundPlayer] that records instead of playing.
class FakeSoundPlayer implements SoundPlayer {
  String? asset;
  int plays = 0;
  bool disposed = false;
  final bool failing;
  final List<String> log;
  FakeSoundPlayer({this.failing = false, required this.log});

  @override
  Future<void> load(String assetPath) async => asset = assetPath;
  @override
  Future<void> play() async {
    if (failing) throw StateError('player broken');
    plays++;
    log.add(asset!);
  }
  @override
  Future<void> dispose() async => disposed = true;
}

/// Makes [FakeSoundPlayer]s for `AudioService.custom(players: fakes.call)`
/// and reads them back: [played] is every cue played, in order.
class FakeSoundPlayers {
  final created = <FakeSoundPlayer>[];
  final log = <String>[];
  final bool failing;
  FakeSoundPlayers({this.failing = false});

  SoundPlayer call() {
    final p = FakeSoundPlayer(failing: failing, log: log);
    created.add(p);
    return p;
  }

  List<FakeSoundPlayer> get live => created.where((p) => !p.disposed).toList();
  List<SoundCue> get played =>
      log.map((a) => SoundCue.values.firstWhere((c) => a.endsWith('/${c.file}.wav'))).toList();
}

/// An [AudioService] on fakes, loaded. `SharedPreferences.setMockInitialValues`
/// must have run.
Future<({AudioService service, FakeSoundPlayers players})> recordingAudio() async {
  final players = FakeSoundPlayers();
  final service = AudioService.custom(players: players.call);
  await service.ready;
  return (service: service, players: players);
}

```dart
import 'dart:async';

import 'package:flutter/foundation.dart';
import 'package:shared_preferences/shared_preferences.dart';

import 'audioplayers_sound_player.dart';

/// The moments that sound (spec §1). Each palette has one file per cue.
enum SoundCue {
  dotFill,
  dotErase,
  trackerOpen,
  trackerClose,
  dialogOpen,
  dialogClose,
  trackerCreate,
  legendAdd,
  yearChange,
  press,
}

/// A folder under assets/sounds: three while they are compared, one ships.
enum SoundPalette { paper, interface, pixel }

extension SoundCueFile on SoundCue {
  /// The file stem: `dotFill` → `dot_fill`.
  String get file => name.replaceAllMapped(RegExp('[A-Z]'), (m) => '_${m[0]!.toLowerCase()}');

  /// The asset path audioplayers wants (relative to `assets/`).
  String assetIn(SoundPalette palette) => 'sounds/${palette.name}/$file.wav';
}

/// One preloaded sound, replayable from its start. The real one wraps an
/// `AudioPlayer`; tests inject a fake that records.
abstract class SoundPlayer {
  Future<void> load(String assetPath);
  Future<void> play();
  Future<void> dispose();
}

/// The app's sounds: one player per cue, preloaded for the current palette;
/// the "Sons" switch and the palette persisted on the device. [play] never
/// throws and never waits — a sound that fails is a debug line, never an
/// error out of a tap.
class AudioService extends ChangeNotifier {
  static const prefEnabled = 'sounds_enabled';
  static const prefPalette = 'sounds_palette';

  static AudioService? _instance;

  /// The app's one service, on real players.
  factory AudioService() => _instance ??= AudioService.custom(players: AudioplayersSoundPlayer.new);

  /// A service on the players [players] makes (tests: fakes).
  AudioService.custom({required SoundPlayer Function() players}) : _makePlayer = players {
    _loading = _init();
  }

  /// Nothing loads, nothing plays (headless tests).
  AudioService.silent() : _makePlayer = null;

  final SoundPlayer Function()? _makePlayer;
  Future<void> _loading = Future.value();
  Map<SoundCue, SoundPlayer> _players = const {};
  int _generation = 0;
  bool _enabled = true;
  SoundPalette _palette = SoundPalette.paper;
  bool _pressPending = false;

  bool get enabled => _enabled;
  SoundPalette get palette => _palette;

  /// Done once the current palette's players are loaded.
  Future<void> get ready => _loading;

  Future<void> _init() async {
    try {
      final prefs = await SharedPreferences.getInstance();
      _enabled = prefs.getBool(prefEnabled) ?? true;
      final name = prefs.getString(prefPalette);
      _palette = SoundPalette.values.firstWhere((p) => p.name == name, orElse: () => SoundPalette.paper);
    } catch (e) {
      debugPrint('AudioService: prefs unavailable: $e');
    }
    notifyListeners();
    await _load();
  }

  /// Loads one player per cue for [_palette]; the previous set is disposed.
  /// A newer generation started meanwhile wins: this one is thrown away.
  Future<void> _load() async {
    final make = _makePlayer;
    if (make == null) return;
    final generation = ++_generation;
    _disposeAll(_players);
    _players = const {};
    final loaded = <SoundCue, SoundPlayer>{};
    for (final cue in SoundCue.values) {
      SoundPlayer? player;
      try {
        player = make();
        await player.load(cue.assetIn(_palette));
        loaded[cue] = player;
      } catch (e) {
        debugPrint('AudioService: ${cue.name} failed to load: $e');
        if (player != null) _disposeAll({cue: player});
      }
    }
    if (generation != _generation) {
      _disposeAll(loaded);
      return;
    }
    _players = loaded;
  }

  void _disposeAll(Map<SoundCue, SoundPlayer> players) {
    for (final p in players.values) {
      unawaited(p.dispose().catchError((Object e) => debugPrint('AudioService: dispose failed: $e')));
    }
  }

  Future<void> setEnabled(bool value) async {
    if (_enabled == value) return;
    _enabled = value;
    notifyListeners();
    await _save((prefs) => prefs.setBool(prefEnabled, value));
  }

  Future<void> setPalette(SoundPalette value) async {
    if (_palette == value) return;
    _palette = value;
    notifyListeners();
    await _save((prefs) => prefs.setString(prefPalette, value.name));
    _loading = _load();
    await _loading;
  }

  Future<void> _save(Future<void> Function(SharedPreferences prefs) write) async {
    try {
      await write(await SharedPreferences.getInstance());
    } catch (e) {
      debugPrint('AudioService: prefs write failed: $e');
    }
  }

  /// Fire and forget. [SoundCue.press] waits one microtask and yields to any
  /// other cue played in the same turn: a button that opens a dialog sounds
  /// as the dialog, not as a button and then a dialog.
  void play(SoundCue cue) {
    if (cue == SoundCue.press) {
      if (_pressPending) return;
      _pressPending = true;
      scheduleMicrotask(() {
        if (!_pressPending) return;
        _pressPending = false;
        _playNow(SoundCue.press);
      });
      return;
    }
    _pressPending = false;
    _playNow(cue);
  }

  void _playNow(SoundCue cue) {
    if (!_enabled) return;
    final player = _players[cue];
    if (player == null) return;
    try {
      unawaited(player.play().catchError((Object e) => debugPrint('AudioService: ${cue.name} failed: $e')));
    } catch (e) {
      debugPrint('AudioService: ${cue.name} failed: $e');
    }
  }

  @override
  void dispose() {
    _generation++;
    _disposeAll(_players);
    _players = const {};
    super.dispose();
  }
}
```

import 'package:audioplayers/audioplayers.dart';
import 'package:flutter/foundation.dart';

import 'audio_service.dart';

/// [SoundPlayer] on audioplayers. The source stays loaded across stops
/// (`ReleaseMode.stop`); low-latency mode on Android (SoundPool; no effect
/// on iOS). The global audio context is set once, by the first player:
/// iOS ambient (the silence switch is honoured, music keeps playing),
/// Android sonification without taking audio focus.
class AudioplayersSoundPlayer implements SoundPlayer {
  static Future<void>? _context;
  final AudioPlayer _player = AudioPlayer();

  static Future<void> _setContext() => _context ??= AudioPlayer.global
      .setAudioContext(AudioContext(
        iOS: const AudioContextIOS(category: AVAudioSessionCategory.ambient),
        android: const AudioContextAndroid(
          contentType: AndroidContentType.sonification,
          usageType: AndroidUsageType.assistanceSonification,
          audioFocus: AndroidAudioFocus.none,
        ),
      ))
      .catchError((Object e) => debugPrint('AudioService: audio context failed: $e'));

  @override
  Future<void> load(String assetPath) async {
    await _setContext();
    await _player.setReleaseMode(ReleaseMode.stop);
    await _player.setPlayerMode(PlayerMode.lowLatency);
    await _player.setSourceAsset(assetPath);
  }

  @override
  Future<void> play() async {
    await _player.stop();
    await _player.resume();
  }

  @override
  Future<void> dispose() => _player.dispose();
}
```

"""The Pixel palette: soft 8-bit-ish cues synthesised with numpy.
Returns {cue: float32 mono array at 44.1 kHz, peak ≤ 1}. Tune the notes here."""
import numpy as np

SR = 44100


def _wave(freq, dur, kind="square", duty=0.25):
    t = np.arange(int(SR * dur)) / SR
    ph = (t * freq) % 1.0
    if kind == "square":
        w = np.where(ph < duty, 1.0, -1.0)
    elif kind == "tri":
        w = 4 * np.abs(ph - 0.5) - 1
    else:
        w = np.sin(2 * np.pi * ph)
    return w.astype(np.float32)


def _env(n, attack=0.004, release=0.06, hold=0.0):
    a, r, h = int(SR * attack), int(SR * release), int(SR * hold)
    s = n - a - h - r
    if s < 0:
        s = 0
    env = np.concatenate([
        np.linspace(0, 1, a, endpoint=False),
        np.ones(h),
        np.ones(s),
        np.linspace(1, 0, r),
    ])
    return env[:n].astype(np.float32)


def _lowpass(x, cutoff=3200.0):
    rc = 1.0 / (2 * np.pi * cutoff)
    alpha = (1.0 / SR) / (rc + 1.0 / SR)
    y = np.empty_like(x)
    acc = 0.0
    for i, v in enumerate(x):
        acc += alpha * (v - acc)
        y[i] = acc
    return y


def note(freq, dur, kind="square", release=0.06, gain=0.8):
    w = _wave(freq, dur, kind)
    return _lowpass(w * _env(len(w), release=release)) * gain


def seq(notes, gap=0.012):
    """notes: [(freq, dur)] played one after another with a short gap."""
    parts = []
    for f, d in notes:
        parts.append(note(f, d))
        parts.append(np.zeros(int(SR * gap), dtype=np.float32))
    return np.concatenate(parts[:-1])


def sweep(f0, f1, dur, gain=0.6):
    t = np.arange(int(SR * dur)) / SR
    f = f0 + (f1 - f0) * t / dur
    ph = np.cumsum(f) / SR
    w = np.where((ph % 1.0) < 0.5, 1.0, -1.0).astype(np.float32)
    return _lowpass(w * _env(len(w), release=0.05)) * gain


C5, E5, G5, C6, A5, F5, D5 = 523.25, 659.25, 783.99, 1046.5, 880.0, 698.46, 587.33


def render():
    return {
        "dot_fill": note(A5, 0.07),
        "dot_erase": sweep(E5, 330.0, 0.09, gain=0.5),
        "tracker_open": seq([(C5, 0.07), (E5, 0.07), (G5, 0.12)]),
        "tracker_close": seq([(G5, 0.07), (E5, 0.07), (C5, 0.12)]),
        "dialog_open": seq([(E5, 0.05), (G5, 0.08)]),
        "dialog_close": seq([(G5, 0.05), (E5, 0.08)]),
        "tracker_create": seq([(C5, 0.06), (E5, 0.06), (G5, 0.06), (C6, 0.16)]),
        "legend_add": seq([(F5, 0.05), (A5, 0.09)]),
        "year_change": sweep(D5, A5, 0.14),
        "press": note(1200.0, 0.025, kind="tri", release=0.015, gain=0.5),
    }

#!/usr/bin/env python3
"""Builds assets/sounds/<palette>/<cue>.wav for the three palettes.

  python3 tools/sounds/build.py paper|interface|pixel|all

paper: Mixkit (Sound Effects Free License), by id; interface: Kenney CC0
packs, by file; pixel: pixel_palette.py. Every source is trimmed of its
leading silence, cut to its length with a fade-out, peak-normalised and
written as 16-bit mono 44.1 kHz wav. Needs ffmpeg and numpy.
Downloads land in tools/sounds/cache/ (git-ignored)."""
import io
import subprocess
import sys
import urllib.request
import wave
import zipfile
from pathlib import Path

import numpy as np

HERE = Path(__file__).resolve().parent
APP = HERE.parent.parent
CACHE = HERE / "cache"
OUT = APP / "assets" / "sounds"
SR = 44100
CUES = ["dot_fill", "dot_erase", "tracker_open", "tracker_close", "dialog_open",
        "dialog_close", "tracker_create", "legend_add", "year_change", "press"]
MAX_MS = {"tracker_open": 700, "tracker_close": 700, "tracker_create": 700}
PEAK_DB = {"press": -10.0}

MIXKIT = "https://assets.mixkit.co/active_storage/sfx/{id}/{id}-preview.mp3"
# cue: (mixkit id, max ms, reverse)
PAPER = {
    "dot_fill": (2376, 160, False),      # Short pencil writing
    "dot_erase": (2380, 220, False),     # Paper quick movement
    "tracker_open": (1104, 600, False),  # Page turn single
    "tracker_close": (1104, 600, True),  # the same page, turned back
    "dialog_open": (1530, 260, False),   # Paper slide
    "dialog_close": (1530, 260, True),
    "tracker_create": (2995, 400, False),  # Stapling paper
    "legend_add": (3102, 300, False),    # Duct tape bandage
    "year_change": (1097, 380, False),   # Turning the newspaper big page
    "press": (1125, 70, False),          # Typewriter soft click
}

KENNEY = {
    "interface-sounds": "https://kenney.nl/media/pages/assets/interface-sounds/fa43c1dd4d-1677589452/kenney_interface-sounds.zip",
    "ui-audio": "https://kenney.nl/media/pages/assets/ui-audio/490d233f68-1677590494/kenney_ui-audio.zip",
}
# cue: (pack, file inside Audio/, max ms)
INTERFACE = {
    "dot_fill": ("interface-sounds", "pluck_001.ogg", 200),
    "dot_erase": ("interface-sounds", "drop_001.ogg", 220),
    "tracker_open": ("interface-sounds", "open_001.ogg", 600),
    "tracker_close": ("interface-sounds", "close_001.ogg", 600),
    "dialog_open": ("interface-sounds", "open_002.ogg", 350),
    "dialog_close": ("interface-sounds", "close_002.ogg", 350),
    "tracker_create": ("interface-sounds", "confirmation_001.ogg", 600),
    "legend_add": ("interface-sounds", "glass_001.ogg", 300),
    "year_change": ("interface-sounds", "scroll_001.ogg", 300),
    "press": ("ui-audio", "click1.ogg", 70),
}


def fetch(url, name):
    CACHE.mkdir(exist_ok=True)
    path = CACHE / name
    if not path.exists():
        req = urllib.request.Request(url, headers={"User-Agent": "Mozilla/5.0"})
        path.write_bytes(urllib.request.urlopen(req, timeout=60).read())
    return path


def decode(data: bytes) -> np.ndarray:
    """Any format ffmpeg reads → float32 mono 44.1 kHz."""
    out = subprocess.run(
        ["ffmpeg", "-v", "error", "-i", "pipe:0", "-f", "f32le", "-ac", "1", "-ar", str(SR), "pipe:1"],
        input=data, stdout=subprocess.PIPE, check=True).stdout
    return np.frombuffer(out, dtype=np.float32).copy()


def shape(x: np.ndarray, cue: str, max_ms: int, reverse=False) -> np.ndarray:
    if reverse:
        x = x[::-1]
    # Leading silence off (−50 dBFS), 2 ms of grace before the first sound.
    peak = np.max(np.abs(x)) or 1.0
    loud = np.flatnonzero(np.abs(x) > peak * 10 ** (-50 / 20))
    start = max(0, loud[0] - int(SR * 0.002)) if len(loud) else 0
    x = x[start:]
    cap = min(max_ms, MAX_MS.get(cue, 400))
    n = min(len(x), int(SR * cap / 1000))
    x = x[:n].copy()
    fade = min(n, int(SR * 0.02))
    x[n - fade:] *= np.linspace(1, 0, fade, dtype=np.float32)
    x *= 10 ** (PEAK_DB.get(cue, -3.0) / 20) / (np.max(np.abs(x)) or 1.0)
    return x


def write(palette: str, cue: str, x: np.ndarray):
    folder = OUT / palette
    folder.mkdir(parents=True, exist_ok=True)
    pcm = (np.clip(x, -1, 1) * 32767).astype("<i2").tobytes()
    with wave.open(str(folder / f"{cue}.wav"), "wb") as w:
        w.setnchannels(1)
        w.setsampwidth(2)
        w.setframerate(SR)
        w.writeframes(pcm)
    print(f"{palette}/{cue}.wav  {len(x) * 1000 // SR} ms")


def build_paper():
    for cue, (sid, max_ms, rev) in PAPER.items():
        data = fetch(MIXKIT.format(id=sid), f"mixkit-{sid}.mp3").read_bytes()
        write("paper", cue, shape(decode(data), cue, max_ms, rev))


def build_interface():
    zips = {pack: zipfile.ZipFile(fetch(url, f"{pack}.zip")) for pack, url in KENNEY.items()}
    for cue, (pack, name, max_ms) in INTERFACE.items():
        z = zips[pack]
        member = next(m for m in z.namelist() if m.endswith("/" + name) or m == name)
        write("interface", cue, shape(decode(z.read(member)), cue, max_ms))


def build_pixel():
    sys.path.insert(0, str(HERE))
    from pixel_palette import render
    for cue, x in render().items():
        write("pixel", cue, shape(x.astype(np.float32), cue, 700))


if __name__ == "__main__":
    which = sys.argv[1] if len(sys.argv) > 1 else "all"
    assert set(PAPER) == set(CUES) == set(INTERFACE)
    if which in ("paper", "all"):
        build_paper()
    if which in ("interface", "all"):
        build_interface()
    if which in ("pixel", "all"):
        build_pixel()
```
